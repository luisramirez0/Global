# Handoff C-01 `project-setup`

## Que se hizo
- `backend/`: Gradle (Groovy) 8.14.8 + Spring Boot 3.5.16, `options.release = 17`, paquete base `ar.global.odonto` (subpaquetes `config security common consultorio usuario paciente agenda recordatorio auditoria`), perfiles `dev` (MySQL por env) y `test` (H2 `MODE=MySQL` + Flyway), `ddl-auto: validate`.
- `GET /api/health` -> `{"status":"UP"}` (publico); `SecurityConfig` stateless deny-by-default (401 sin cuerpo); `CorsConfig` con origenes desde `CORS_ALLOWED_ORIGINS` (sin `*`).
- `frontend/`: Vite + Vitest (jsdom) + ESLint 9 + TypeScript estricto; `resolveApiBaseUrl`, `mountApp` (sin `innerHTML`), test que protege la regla `no-explicit-any`.
- Raiz: `.env.example`, `.gitignore` ampliado, `docker-compose.yml` (mysql 8.4 / backend / frontend nginx), Dockerfiles, `scripts/test.sh`.
- Docs: DD-10 en KB 09, comentario de CODEOWNERS.

## Como se verifico
- `bash scripts/test.sh`: backend 15 tests, frontend 9 tests, en verde. `npm run lint` y `npm run typecheck` limpios; `npm run build` OK.
- `docker compose --env-file .env.example config --services` -> mysql, backend, frontend (no se ejecuto `up` ni `build`, regla 9).
- Mutaciones temporales comprobadas: `anyRequest().permitAll()` rompe `SecurityDefaultDenyIT`; desactivar `no-explicit-any` rompe el test de tooling; un test roto hace fallar `scripts/test.sh` (rc=1).

## Pendiente / a cargo de la persona

- Aviso a integrante-1/2: se toco `security/` (zona de riesgo, regla 12): `SecurityConfig`, CSRF deshabilitado a proposito (API stateless sin cookies; C-03 debe reactivarlo si DD-04 elige cookie HttpOnly).
- Commit/PR solo con autorizacion (rama `C-01-project-setup`).

## Decisiones / notas
- Spring Initializr ya solo ofrece Boot >= 4.0: el `build.gradle` se escribio a mano con Boot 3.5.16; del starter solo se tomaron los scripts del wrapper y se fijo Gradle 8.14.8 con `distributionSha256Sum`.
- `docker-compose.yml` exige `.env` (`env_file`): `docker compose config` sin `.env` falla; usar `--env-file .env.example ... --services` para validar.
- `@eslint/js` fijado en 9.x (la 10 exige eslint 10).
